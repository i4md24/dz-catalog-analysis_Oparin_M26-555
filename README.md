## dz-catalog-analysis — Домашнее задание №1. Анализ каталога фильмов стримингового сервиса
Итоговое задание курса «Программирование на Python»: сквозной мини-проект из 9 этапов,объединяющий материал от переменных и чисел до множеств, словарей, итераторов игенераторов. Результат - единственный исполняемый файл catalog_analysis.py, которыйпри запуске печатает демо-выводы всех этапов и итоговый отчет по каталогу. Вся логика реализована вручную, без pandas/numpy и классов (процедурный стиль).

## Стек и инструменты
Python 3.12 - версия зафиксирована в .python-version;
uv - управление проектом, зависимостями и запуском скрипта;
ruff (dev-зависимость) - линтер: правила E (стиль PEP8), F (частые ошибки), I (порядок импортов); line-length 88, target py312 - конфиг в pyproject.toml;

## Как запустить
uv sync                      # установка зависимостей (ruff) в окружение проекта
uv run catalog_analysis.py   # запуск решения, демо всех этапов и печать отчета
uv run ruff check .          # проверка стиля линтером: ожидается "All checks passed!"
